# SMR Projects - Agent & Project Guidelines

## Project Location Rule
- **Mandatory Root Directory**: `D:\SMR-Projects`
- Whenever starting or creating ANY new project, ALWAYS create a new folder under this directory:
  `D:\SMR-Projects\<project-name>`
- Never create project directories in temp, Desktop, or default OS user folders unless explicitly directed.
- Keep all files, code, tests, and build artifacts organized within each respective project directory under `D:\SMR-Projects\`.
- **Bharakhatta Project Location**: `D:\SMR-Projects\bharakhatta`
